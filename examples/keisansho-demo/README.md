# デモ：計算書サンプルの再現

`samples/計算書サンプル.pdf`（p.18〜48）を、formDoc の部品だけで再現した文書（`document.json`）。
「部品で作成」で開くと、計算書の文書テンプレートで組版され、エラー0件で PDF を出力できる。

```bash
cargo run -p formdoc-cli -- gui examples/keisansho-demo/document.json demo.pdf
```

## 再現した範囲

| サンプル | 内容 | 使った部品 |
|---|---|---|
| p.18 | 3.2 設計結果一覧表 (1) 主桁 | 表（セルの結合・縦書き） |
| p.21〜25 | 4.1 作用（死荷重〜地震の影響） | 内訳と合計・変数定義・計算・照査・記号説明・基準引用 |
| p.26〜32 | 4.2 断面力の算出（曲げモーメント・せん断力・軸力） | 計算（本文には表示しない）と、値を `{{変数}}` で参照する表 |
| p.33〜36 | 4.3 作用の組合せおよび設計応答値のまとめ（A点〜e点） | 組合せの max / min を計算し、表に集計 |
| p.37〜39 | 4.4 反力と反力のまとめ | 計算・内訳と合計・表 |
| p.40〜48 | 4.5 耐荷性の照査（板要素・断面耐力・部材の照査） | **断面諸量（I形）**（計算ロジックの部品）・計算・照査 |

サンプルに載っている主要な値（死荷重 5.88 kN/m、衝撃係数 0.425、e点の設計曲げモーメント 705.61 kN·m、断面積 23,550 mm²、
M_ucd = 972.1 kN·m、上フランジの照査 0.956 など）は、すべて計算で同じ値になる。作成時に、出力した PDF の文字とサンプルの値
115 項目を突き合わせて確かめた。回帰テスト（`crates/formdoc-core/tests/demo.rs` の `keisansho_demo_reproduces_the_sample`）では、
そのうち主な値と照査の結果（すべて OK）を確かめている。

§1 設計概要・§2 設計条件はサンプルに無いため、計算書の章の決まり（構造形式：上路桁）に沿って短い文章を入れた。

## サンプルと違う点

- **図**：影響線の載荷図・風荷重の作用図・荷重の配置図は入れていない（影響線縦距の和などの値は表で示した）。
- **表**：3.2 の (2) 横桁・(3) 支承の表、4.3 の耐疲労性の組合せは入れていない（サンプルの耐疲労性の値は、本文に式が無く再現できないため）。
- **数値の桁区切り**：計算書の文書テンプレートで 4桁から区切る設定にしたため、サンプルで区切りの無い「1892.3」「9428」などは「1,892.3」「9,428」になる。
- **単位の換算**：N・N·mm で書かれた途中の値（「934149 N = 934.1 kN」など）は、式の中で 1000・1000000 で割って kN・kN·m で示した。
